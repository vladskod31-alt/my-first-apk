# Сервер аккаунтов и SMS

Этот компонент нужен только для **реальной проверки номера и разрешённого поиска по телефону**. Переписка по нику работает отдельно. Сервер не хранит сообщения, пароли локального хранилища или закрытые ключи переписки.

## Запуск на собственном хостинге

1. Node.js 22.13+ с `node:sqlite`. Установите зависимости: `npm ci --omit=dev`.
2. Создайте настоящий Twilio Verify Service. В своём кабинете настройте разрешённые страны, ограничения стоимости и защиту от SMS-накрутки. Проверьте доступность SMS для нужных операторов. Доставка SMS здесь не была испытана на реальном провайдере.
3. Заполните локальный `.env` по `.env.example` либо переменные защищённого окружения хостинга:
   - `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_VERIFY_SERVICE_SID`;
   - `ACCOUNT_DB` — файл SQLite **на постоянном приватном томе вне web-root**;
   - `ALLOWED_ORIGINS` — список точных HTTPS-origin через запятую. Для APK: `https://appassets.androidplatform.net`. Для веб-клиента добавьте адрес его развёртывания. Не используйте `*`;
   - `MAX_SMS_PER_DAY=25` — общий стартовый лимит запросов SMS за скользящие 24 часа;
   - `TRUST_PROXY=1` — только если сервис доступен исключительно через один доверенный reverse proxy. Без этого оставьте `0`.
4. `npm run server`. Сервис слушает `0.0.0.0:3000` (или `PORT`). Завершение TLS обязательно настройте на reverse proxy. Не открывайте незашифрованный сервер в интернет.
5. В приложении: **Настройки подключения → Сервер аккаунтов и SMS** = `https://ваш-домен/api`. Для своего сигналинга используйте `https://ваш-домен/peerjs`. TURN разворачивается отдельно.
6. Сохраните номер в профиле, нажмите **Подтвердить по SMS**, согласитесь на передачу номера и введите код из реально полученного SMS. После подтверждения можно отдельно включить **Поиск меня по номеру**; по умолчанию он выключен.

Ключи Twilio используются **только сервером**. Никогда не задавайте их через переменные `VITE_*`, не включайте в APK, не передавайте в чат и не сохраняйте в Git. `VITE_ACCOUNT_SERVER` может содержать только публичный HTTPS-адрес API, вшиваемый в клиент во время сборки.

Если переменные провайдера не заданы, `/features` возвращает `sms: false`, а запрос SMS — `503 SMS_NOT_CONFIGURED`. Универсального кода, демонстрационной проверки или обхода SMS нет. В автоматических тестах провайдер явно подменяется тестовым объектом; обычный сервер этот режим не предлагает.

## Протокол и ограничения

- `/sms/request`: проверенный E.164, случайный challenge/nonce, срок 5 минут. Не чаще раза в минуту и пяти запросов на номер в сутки; до 15 на IP-хэш в сутки; общий бюджет по `MAX_SMS_PER_DAY`.
- `/sms/verify`: до пяти попыток. Реальный ответ Twilio должен быть `approved`. Клиент подписывает challenge, номер, ник, публичный ключ и настройку поиска своим ключом ECDSA. Challenge погашается атомарно и не создаёт несколько сеансов при конкурентных запросах.
- Сеанс — случайный 256-битный bearer token на 30 дней. В БД сохраняется только SHA-256 токена. Новый SMS-вход отзывает прежние сеансы этого номера.
- `/me`: просмотр, изменение видимости в поиске, удаление телефонного аккаунта.
- `/contacts/find`: только с действующим сеансом, до 50 поисков в сутки на сеанс. Номер без согласия на поиск возвращает тот же `404`, что и отсутствующий. Возвращаются ник и отпечаток публичного ключа для проверки P2P-соединения.
- Метаданные запросов SMS очищаются спустя двое суток при следующих запросах. Истёкшие сеансы и счётчики поиска также очищаются. Сам аккаунт хранится до удаления владельцем.

SQLite содержит номера, ники, публичные ключи и лимиты запросов. Это **не** клиентское AES-хранилище. Защитите сервер, права доступа, том и резервные копии; при необходимости используйте шифрование диска. Хэш IP не следует считать гарантией анонимности. SMS-провайдер видит номер и хранит свои журналы по собственным правилам. Удаление аккаунта не удаляет копии контактов у других людей или журналы оператора.

Для реального запуска нужны мониторинг, резервирование, политика обработки персональных данных, контроль счетов SMS и независимый аудит. Эти эксплуатационные задачи и реальная доставка SMS не считаются выполненными наличием этого модуля.
