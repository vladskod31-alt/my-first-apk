# Зеркало APK для тега релиза

`LIBO-2.8.7.apk` — подписанный установочный файл для Android 8.0+ (API 26+), пакет
`app.libo.messenger`, versionCode 20807, версия 2.8.7.

> ⚠️ Важно о подписи 2.8.7.
>
> Релизный кейстор хранится владельцем вне репозитория (см. RELEASE_NOTES.md) и не
> передаётся в это окружение. Поэтому собранный здесь APK подписан **временным
> тестовым ключом** песочницы, отпечаток сертификата
> `91937ef538f670dae176559ab69b6dc3b54e4245e4a1d67783127bf0658e6bca`
> (CN=LIBO Release, O=LIBO Messenger, RSA-4096, схемы v1+v2+v3).
>
> Это не тот ключ, которым подписаны 2.8.0/2.8.1 (`f4e4b3e5…dba4` и `d5e09a20…`).
> Значит, Android **не установит этот файл поверх прежней версии**: перед установкой
> сделайте Настройки → «Резервная копия: экспорт текста», удалите прежнюю версию LIBO,
> установите 2.8.7 и импортируйте копию. Для свежей установки дополнительных действий
> не нужно.

Каталог существует как гарантированная ссылка на файл релиза: загрузка бинарных
release-assets через `uploads.github.com` из среды сборки обрывалась, а обычный Git
push работает. Файл тега `v2.8.7` неизменяем, поэтому ссылка стабильна. Правильный
APK, подписанный релизным ключом владельца, загружается вручную или из CI при наличии
секретов подписи (`release.yml`).

Контрольная сумма — в `SHA256SUMS.txt` рядом. Перед установкой прочитайте ограничения
тестового релиза (`../RELEASE_NOTES.md`, `../KNOWN_ISSUES.md`) и список проверок
(`../TESTING.md`).

Не кладите сюда keystore, пароли, историю переписки и любые другие личные данные.
Бинарные файлы в Git — вынужденная мера для тегов релизов; обычные ветки их не содержат
(`*.apk` в `.gitignore`, исключение только для этого файла).
