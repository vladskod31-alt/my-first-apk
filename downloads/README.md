# Зеркало APK для тега релиза

Файл `LIBO-2.8.1.apk` — подписанный установочный файл (релизный ключ RSA-4096 после
ротации в 2.8.0, схемы v2 и v3) для Android 8.0+ (API 26+), пакет
`app.libo.messenger`.

Каталог существует как гарантированная ссылка на файл релиза: загрузка бинарных
release-assets через `uploads.github.com` из среды сборки обрывалась, а обычный Git push
работает. Файл тега `v2.8.1` неизменяем, поэтому ссылка стабильна. Зеркалом служит
release-asset того же релиза (`releases/download/v2.8.1/LIBO-2.8.1.apk`): его загружает
workflow `release.yml` с повторами, а при недоступности загрузок файл можно прикрепить
вручную.

Контрольная сумма — в `SHA256SUMS.txt` рядом; отпечаток сертификата подписи и порядок
проверки — в `../RELEASE_NOTES.md` и `../SECURITY.md`. Перед установкой прочитайте
ограничения тестового релиза (`../RELEASE_NOTES.md`, `../KNOWN_ISSUES.md`) и список
проверок (`../TESTING.md`): на физическом Android-устройстве APK в среде сборки не
запускался.

Не кладите сюда keystore, пароли, историю переписки и любые другие личные данные.
Бинарные файлы в Git — вынужденная мера для тегов релизов; обычные ветки их не содержат
(`*.apk` в `.gitignore`, исключение только для этого файла).
