# Зеркало APK для тега релиза

`LIBO-2.8.4.apk` — установочный файл для Android 8.0+ (API 26+), пакет
`app.libo.messenger`, versionCode 20804, версия 2.8.4.

> ⚠️ Важно о подписи 2.8.4.
>
> Релизный кейстор хранится владельцем вне репозитория (см. RELEASE_NOTES.md) и не
> передаётся в среду сборки. Поэтому собранный здесь APK подписан **временным
> тестовым ключом** песочницы, отпечаток сертификата
> `26e33f79cafc8ee1ab3fb32d272bf08bdf8736280cf32cad4df4385060f6336a`
> (CN=LIBO Release, O=LIBO Messenger, RSA-4096, схемы v2+v3).
>
> Это не ключ 2.8.0 (`f4e4b3e5…dba4`) и не ключ песочницы 2.8.1 (`d5e09a20…`). Android
> **не установит этот файл поверх предыдущей версии**: перед установкой сделайте
> Настройки → «Резервная копия: экспорт текста», удалите прежнюю версию LIBO,
> установите 2.8.4 и импортируйте копию. Для свежей установки дополнительных
> действий не нужно.

Каталог существует как гарантированная ссылка на файл релиза. Файл тега `v2.8.4`
неизменяем, поэтому ссылка стабильна. APK, подписанный релизным ключом владельца,
загружается владельцем вручную или из CI при наличии секретов подписи (`release.yml`).

Контрольная сумма — в `SHA256SUMS.txt` рядом. Перед установкой прочитайте ограничения
тестового релиза (`../RELEASE_NOTES.md`, `../KNOWN_ISSUES.md`), архитектуру защиты
(`../docs/SECURITY_ARCHITECTURE.md`) и список проверок (`../TESTING.md`).

Не кладите сюда keystore, пароли, историю переписки и любые другие личные данные.
