# Збірки

Бінарні APK та ZIP не відстежуються в поточному дереві джерел. Скрипт `scripts/build-apk-local.sh` формує APK у `artifacts/`, а `npm run package:private` створює локальні матеріали передачі в `deliverables/`.

До публічного PR 2.3 входить код, не готові інсталяційні файли чи приватні дані. Раніше опубліковані артефакти можуть залишатися в історії Git/попередніх версіях; цей PR не переписує історію.
