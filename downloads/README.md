# Готовый APK первой беты

`LIBO-2.0.0-beta.1.apk` — настоящий подписанный установочный файл для Android 8.0+.

Обычно APK следует хранить в GitHub Releases, а не Git. Здесь сделано одно небольшое исключение для прямого запроса пользователя: соединение с `uploads.github.com` при загрузке release assets обрывается, а обычный Git push работает. Файл доступен из тега `v2.0.0-beta.1`; `SHA256SUMS.txt` позволяет проверить целостность.

Подпись тестовая (debug), не production. Перед установкой прочитайте [ограничения](../RELEASE_NOTES.md) и [что проверено](../TESTING.md). На реальном Android-устройстве APK ещё не тестировался.

Не кладите сюда keystore, пароли или историю переписки. Для следующих версий предпочтительны assets в Releases.
