# Завантажити LIBO 2.8.8 (експериментально)

[APK у GitHub Releases](https://github.com/vladskod31-alt/my-first-apk/releases/download/v2.8.8/LIBO-2.8.8.apk) · [Дзеркало APK](LIBO-2.8.8.apk)

Android 8.0+; `app.libo.messenger`, versionCode 20808. APK підписаний v2/v3. `SHA256SUMS.txt` — сума файлу, `SIGNING.txt` — перевірений сертифікат, `APK-INFO.txt` — пакет/версія/дозволи. `ICON-VERIFICATION.json` та `ICON-FROM-APK.png` підтверджують ресурси нової іконки всередині APK.

## Установка без втрати важливих даних

1. **Не видаляйте старий LIBO одразу.** Спочатку експортуйте текст через налаштування та перевірте збережений JSON. Фото збережіть окремо.
2. Експорт **не містить** фото, приватних ключів, ідентичності та налаштувань. Імпорт відновлює лише текстовий архів для читання, не живі сесії. Якщо потрібна стара історія/ідентичність — залиште старий застосунок і протестуйте на другому телефоні.
3. Попередній ключ недоступний; новий сертифікат відрізняється. Android відхилить встановлення поверх інакше підписаної версії. Для чистої установки знадобиться видалення старої **після** збереження важливого; воно знищить старий Android Keystore і чати.
4. Відкрийте APK на Android, дозвольте встановлення з цього джерела та встановіть. Фізичне встановлення цієї збірки ще не перевірене — повідомте модель/Android, якщо є помилка.
5. У разі потреби імпортуйте текстовий архів, знову обміняйтеся кодами з контактами.
