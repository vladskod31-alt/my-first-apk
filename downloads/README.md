# Зеркало APK для тега релиза

`LIBO-2.8.2.apk` — подписанный установочный файл для Android 8.0+ (API 26+), пакет
`app.libo.messenger`, versionCode 20802, версия 2.8.2, 12 функций в стиле Telegram плюс
два бонуса (ночная тема по расписанию и защита от скриншотов).

SHA-256 файла: `594a2dbc5814baebc2152929283b7f2eb1761423960bc63da28209e56cb4c279`
(см. `SHA256SUMS.txt` рядом).

Тот же файл приложен к релизу `v2.8.2` как его файл:
https://github.com/vladskod31-alt/my-first-apk/releases/download/v2.8.2/LIBO-2.8.2.apk
(загружено workflow `publish-asset.yml` из GitHub Actions). Этот каталог — зеркало на
случай недоступности `uploads.github.com`.

`LIBO-2.8.1.apk` оставлен как предыдущая версия: versionCode 20801, версия 2.8.1,
SHA-256 `47d67439f22eb3db3e704a2075b1df0449e5de01853e2a0b723a3ad5acd4536b`.

> ⚠️ Важно о подписи 2.8.2.
>
> Релизный кейстор хранится владельцем вне репозитория (см. RELEASE_NOTES.md) и не
> передаётся в это окружение. Поэтому собранный здесь APK подписан **временным
> тестовым ключом** песочницы, отпечаток сертификата
> `d6bc33ca85e16d1365fa7bea1d56fd1497ca48ed54390dd897bc08136457678e`
> (CN=LIBO Release, O=LIBO Messenger, RSA-4096, схемы v1+v2+v3).
>
> Это не ключ 2.8.0 (`f4e4b3e5…dba4`) и не ключ зеркального APK 2.8.1 (`d5e09a20…5e9a`).
> Значит, Android **не установит этот файл поверх** уже стоящей LIBO, подписанной другим
> ключом: перед установкой сделайте Настройки → «Резервная копия: экспорт текста»,
> удалите прежнюю версию LIBO, установите 2.8.2 и импортируйте копию (она откроется как
> архив только для чтения). Для свежей установки дополнительных действий не нужно.

Каталог существует как гарантированная ссылка на файл релиза: загрузка бинарных
release-assets через `uploads.github.com` из среды сборки обрывалась, а обычный Git push
работает. Файлы тегов `v2.8.1` и `v2.8.2` неизменяемы, поэтому ссылки стабильны.
Правильный APK, подписанный ключом владельца, загружается вручную или из CI при наличии
секретов подписи (`release.yml`).

Проверьте контрольную сумму перед установкой:

```sh
curl -fsSL https://github.com/vladskod31-alt/my-first-apk/raw/refs/tags/v2.8.2/downloads/SHA256SUMS.txt | sha256sum -c --ignore-missing -
```

Перед установкой прочитайте ограничения тестового релиза (`../RELEASE_NOTES.md`,
`../KNOWN_ISSUES.md`) и список проверок (`../TESTING.md`).

Не кладите сюда keystore, пароли, историю переписки и любые другие личные данные.
Бинарные файлы в Git — вынужденная мера для тегов релизов; обычные ветки их не содержат
(`*.apk` в `.gitignore`, исключения только для файлов этого каталога).
