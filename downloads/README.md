## Установка

1. Если стояла любая предыдущая сборка LIBO — сначала сделайте экспорт:
   **Настройки → Резервная копия: экспорт текста**. Затем удалите старое приложение:
   подписи тестовых сборок различаются, и Android не устанавливает обновление поверх.
   База зашифрована ключом Android Keystore, который удаляется вместе с приложением, —
   восстановить чаты без экспорта нельзя.
2. Разрешите установку из неизвестных источников (настройка запрашивается при установке).
3. Установите `LIBO-2.8.7.apk` и импортируйте копию:
   **Настройки → Восстановить из копии** (архив только для чтения).

При первом запуске LIBO попросит разрешения на уведомления (нужны для сообщений в фоне)
и, если включите Bluetooth P2P, — разрешения Bluetooth/локации для поиска устройств рядом.

Эта сборка заменяет первую публикацию 2.8.7 (исправлены иконка и чёрный сплэш);
полный список изменений — в `RELEASE_NOTES.md` репозитория.
