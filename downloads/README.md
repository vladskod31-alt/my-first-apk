# Зеркало APK для тега релиза

`LIBO-2.8.1.apk` — подписанный установочный файл для Android 8.0+ (API 26+), пакет
`app.libo.messenger`, versionCode 20801, версия 2.8.1.

> ⚠️ Важно о подписи 2.8.1.
>
> Релизный кейстор хранится владельцем вне репозитория (см. RELEASE_NOTES.md) и не
> передаётся в это окружение. Поэтому собранный здесь APK подписан **временным
> тестовым ключом** песочницы, отпечаток сертификата
> `d5e09a206a56946caccf30e81ad137feabec2b603cef5a18087c3f6ec4565e9a`
> (CN=LIBO Release, O=LIBO Messenger, RSA-4096, схемы v2+v3).
>
> Это не тот ключ, которым подписан 2.8.0 (`f4e4b3e5…dba4`). Значит, Android
> **не установит этот файл поверх 2.8.0**: перед установкой сделайте
> Настройки → «Резервная копия: экспорт текста», удалите прежнюю версию LIBO,
> установите 2.8.1 и импортируйте копию. Для свежей установки дополнительных
> действий не нужно.

Каталог существует как гарантированная ссылка на файл релиза: загрузка бинарных
release-assets через `uploads.github.com` из среды сборки обрывалась, а обычный Git
push работает. Файл тега `v2.8.1` неизменяем, поэтому ссылка стабильна. Правильный
APK, подписанный тем же ключом, что и 2.8.0, загружается владельцем вручную или из CI
при наличии секретов подписи (`release.yml`).

Контрольная сумма — в `SHA256SUMS.txt` рядом. Перед установкой прочитайте ограничения
тестового релиза (`../RELEASE_NOTES.md`, `../KNOWN_ISSUES.md`) и список проверок
(`../TESTING.md`).

Не кладите сюда keystore, пароли, историю переписки и любые другие личные данные.
Бинарные файлы в Git — вынужденная мера для тегов релизов; обычные ветки их не содержат
(`*.apk` в `.gitignore`, исключение только для этого файла).
