# LIBO 2.8.9.1 — завантаження

Android 8.0+ із сучасним WebView, `app.libo.messenger`, versionCode 2080901. Перевірені v2/v3, zipalign, package/version та ресурси іконки. SHA256SUMS.txt, SIGNING.txt, APK-INFO.txt та ICON-VERIFICATION.json стосуються **2.8.9.1**. Старий APK 2.8.8 залишається історичним; його сума — у попередньому релізі.

**Підпис новий:** SHA-256 сертифіката `1e12bb359114d2a1f2d5d2e9e975fb69b20c3f6ce85377cef5c81880748f10b1`. Ключ 2.8.8 недоступний у новій сесії. Android не дозволяє in-place update з іншим сертифікатом.

1. Не видаляйте старий застосунок без збереження важливого. Текст експортуйте через налаштування; фото збережіть окремо.
2. Текстовий експорт **не переносить фото/ключі/ідентичність/налаштування/гаманець Orbit**. Імпорт — лише архів для читання. Для збереження старої ідентичності тестуйте на іншому пристрої.
3. Лише після збереження важливого можна видалити стару версію і встановити новий APK. Видалення знищує Android Keystore/стару історію.
4. Після встановлення: Налаштування → Orbit Premium. Валюта віртуальна; реклама й аналітика вимкнені за замовчуванням.

Фізичні пристрої, Direct/NFC та production-рекламний сервер не протестовані. Це experimental prerelease, не Google Play-публікація. [Межі випуску](../docs/TELEGRAM-SCOPE.md).
