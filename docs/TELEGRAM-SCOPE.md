# Межі 2.8.9.1: це не копія всього Telegram

LIBO — окремий P2P-проєкт без зв’язку з Telegram. Випуск додає власні назви й економіку, а не імітує Telegram Premium/Stars.

| Напрям | Стан |
|---|---|
| Особисті чати, фото, файли, відповіді, редагування, видалення, реакції, пошук | успадковані функції LIBO; браузерні регресійні тести |
| Форматування, спойлери, папки, опитування, стікери, відкладені повідомлення | успадковано з 2.8.7/2.8.8 |
| Голосові виклики | власний foreground-only WebRTC, не Telegram calls; без фонових/групових викликів |
| Premium, монети, зірки | нова локальна демо-економіка, без грошей/переказів/серверного обліку |
| Реклама | власна opt-in студія + self-hosted API, не Telegram Ads; сервер не розгорнуто автоматично |
| Групи, канали, ролі адміністраторів | **не реалізовано**; потрібні протокол членства й маршрутизація |
| Хмарна історія, синхронізація кількох пристроїв | **не реалізовано**; потрібні сервери, керування ключами й відновлення |
| Bot API, мініапи, stories, livestream, відеовиклики | **не реалізовано** |
| Реальні платежі, подарунки між людьми, маркетплейс | **не реалізовано**; потрібні серверний ledger, провайдер і правила продажу |
| Масштабована доставка/push, модерація, антиспам/антифрод | не еквівалентні Telegram; поточні локальні/мережеві ліміти не замінюють серверну систему |

Наступний великий етап варто обирати окремо: групи/канали або серверну синхронізацію. Не видаємо ці пункти за вже додані.
