# Перевірка LIBO 2.3.0 — 8 вересня 2026

> Звіт нижче фіксує перевірки збірки від 8 вересня. 12 вересня власник окремо дозволив публічний PR з кодом; артефакти та секрети не входять до нього.

## Перевірка перед PR — 12 вересня 2026

Повторно виконано `npm test` (**48/48**), `npm run test:e2e` (**23/23**), `npm run build` (успіх, лише попередження про розмір emoji-бандла) та `npm audit` (**0** відомих вразливостей у поточній відповіді реєстру). Перевірено індекс Git: немає APK/ZIP, вбудованих копій APK, баз, `.env` чи приватних ключів. Перенесення рядків у повідомленні Preact нормалізовано без зміни ліцензійного тексту.

Ця перевірка PR не є новим запуском на фізичному Android або розгортанням хостингу. Нижче збережено результати попередньої збірки APK.

- **23/23** Playwright-тести: попередні сценарії плюс кольори/фон/капсули, локальна фонова фотографія, збереження при перезапуску, повідомлення відсутньому клієнту через сервер, повернення/прочтення, відновлення на новій інсталяції й окремий дозвіл сповіщень через заглушку Java bridge.
- Production web build успішний; є попередження про великий пакет даних emoji.
- Java/DEX/Android-ресурси зібрано перевіреним запасним toolchain. **10 попереджень про deprecated API**, без помилок.
- Перевірено APK v2/v3, RSA 3072, zipalign та CRC ZIP.
- Перевірено ресурси, витягнуті саме з фінального APK, у Chromium на нативному HTTPS-origin з CSP, без зовнішньої HTTP/WebSocket-мережі: локальні нотатки, SVG, мови, оформлення, порожній production URL хмари, парольне сховище, перезапуск і мобільна ширина.
- Серверний ZIP розпаковано; `npm ci --omit=dev --ignore-scripts` і завантаження обох API-модулів успішні. Docker/VPS розгортання не виконувалось.
- `npm audit`: **0** відомих вразливостей у відповіді реєстру на момент перевірки.
- Приватний архів перевірено: APK усередині побайтово збігається з окремим файлом. У серверному пакеті немає `.env`, баз, ключів підпису або файлів паролів.

## Не завершено / не перевірено

- **Точна іконка користувача не встановлена:** JPG із чату відсутній у робочій папці. Поточна збірка має попередню іконку. JPG підтримується; потрібен доступний файл, наприклад усередині ZIP. Приблизну заміну не зроблено.
- Постійний хостинг не наданий і не розгорнутий. Хмарні функції потребують власного HTTPS-сервера, як погоджено з користувачем.
- Фізичний Android/емулятор, Doze, boot, force-stop, системні діалоги, справжні сповіщення та різні мобільні мережі не тестувались. Заглушка bridge не замінює ці перевірки.
- Немає незалежного криптоаудиту; хмарний режим не є Signal Double Ratchet.
- APK не оновлює старі пакети і не переносить їх локальні дані автоматично.
- **Жодні файли 2.3 не завантажувалися в GitHub.**

JPG можна перетворити локально через `node scripts/apply-icon.mjs /path/to/icon.jpg`, після чого потрібна нова збірка й перевірка.
