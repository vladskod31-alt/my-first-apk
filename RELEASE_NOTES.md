## Подпись

APK из каталога `downloads/` собран в песочнице без релизного кейстора владельца и
подписан **временным тестовым ключом** (RSA-4096, схемы v2 + v3):

```text
Signer #1 certificate SHA-256 digest: 26e33f79cafc8ee1ab3fb32d272bf08bdf8736280cf32cad4df4385060f6336a
Owner: CN=LIBO Release, O=LIBO Messenger
```

Это не ключ 2.8.0 (`f4e4b3e5…dba4`) и не временный ключ 2.8.1 (`d5e09a20…`), поэтому
поверх уже установленной версии этот файл не встанет: сделайте Настройки → «Резервная
копия: экспорт текста», удалите прежнюю версию, установите 2.8.2 и импортируйте копию.
APK, подписанный релизным ключом владельца, публикуется из CI (`release.yml`) при
наличии секретов подписи — тогда обновление с 2.8.0/2.8.1 ставится поверх.

## Что нового в 2.8.2 — 🔐 LIBO SECURITY

Полное описание архитектуры и того, что именно реализовано, — в
[docs/SECURITY_ARCHITECTURE.md](docs/SECURITY_ARCHITECTURE.md).

1. **Сквозное шифрование нового поколения.** X25519 (обмен ключами), Ed25519
   (личность и подписи), Double Ratchet (прямая секретность: ключ меняется на каждое
   сообщение), ChaCha20-Poly1305 (шифрование сообщений). Примитивы — аудированные
   библиотеки `@noble/*`; конструкции — спецификации Signal. Собеседники на 2.8.1
   продолжают работать через прежний MT-слой; после предложения E2EE открытый текст
   от этой стороны игнорируется (защита от даунгрейда).
2. **Личность устройства и номер безопасности.** У каждого устройства — пара ключей
   Ed25519/X25519. Ключ собеседника закрепляется при первом контакте, смена ключа
   показывается баннером, номер безопасности (60 цифр) одинаков у обоих и
   подтверждается вручную. В шапке чата — значок замка (зелёный после подтверждения).
3. **QR-приглашение с открытым ключом и одноразовым токеном.** QR содержит личный код,
   открытый ключ подписи и токен на 10 минут. Контакт, добавленный из такого
   приглашения, автоматически принимается и его ключ проверяется — несовпадение
   отклоняет соединение. Закрытых ключей и паролей в QR нет (проверяется тестом).
4. **Зашифрованное хранилище.** История чатов и ключи устройства лежат в IndexedDB
   зашифрованными AES-256-GCM. На Android ключ хранилища обёрнут ключом из Android
   Keystore (StrongBox/TEE, если есть). Записи 2.8.1 переносятся автоматически.
5. **Локальная защита.** `FLAG_SECURE` (нет скриншотов и превью в недавних), биометрия
   поверх PIN (системный BiometricPrompt), автоблокировка через 30 с / 1 мин / 5 мин,
   растущая задержка после ошибок PIN, кнопка «Заблокировать сейчас».
6. **Сессии и ключи.** Экран «Активные сессии и ключи»: отпечаток устройства, список
   защищённых каналов, отзыв сессии, пересоздание ключей устройства.

## Установка и обновление

1. Скачайте `LIBO-2.8.2.apk` из каталога `downloads/` тега `v2.8.2` и проверьте SHA-256.
2. Разрешите установку из браузера или файлового менеджера (Android 8–13), либо откройте
   файл напрямую (Android 14+).
3. Откройте LIBO на обоих устройствах, покажите QR или отправьте приглашение.

Файл из `downloads/` подписан временным ключом — см. раздел «Подпись»: перед установкой
поверх 2.8.0/2.8.1 нужен экспорт копии и чистая переустановка.

## Проверка сборки

`npm test` (33 модульных теста, включая 9 тестов E2EE: подписи, рэтчет, порядок,
повторы, подделка, MITM, уникальность nonce, лимит пропусков, обнуление ключей) и
`npm run test:e2e` (9 браузерных сценариев с двумя независимыми клиентами, включая
совпадение номера безопасности и отзыв сессии) проходят. Манифест: код 20802, minSdk 26,
targetSdk 35, единственное разрешение `INTERNET`, `debuggable=false`, `FLAG_SECURE`.

## English summary

LIBO 2.8.2 introduces the LIBO SECURITY architecture: X25519 + Ed25519 identities, a
Signal-style Double Ratchet with ChaCha20-Poly1305 (audited `@noble` primitives, no
home-grown crypto), identity pinning with safety numbers and key-change warnings, QR
invitations carrying only public keys plus a one-time pairing token, an AES-256-GCM
encrypted local vault whose key is wrapped by Android Keystore, FLAG_SECURE, biometric
unlock, auto-lock, a sessions screen with revocation and identity rotation — plus
twenty Telegram-style features (formatting, spoilers, scheduled and silent messages,
per-chat auto-delete, archive, pinned chats, nicknames, chat colours, voice speed,
swipe-to-reply, unread divider, delete-for-me, privacy toggles, bio, font size,
auto-lock, sessions, stickers, draft previews). Bluetooth P2P and Tor remain on the
roadmap; see docs/SECURITY_ARCHITECTURE.md.

## Что нового в 2.8.1

1. **Интерфейс без упоминаний открытого кода.** Из экрана «О LIBO», подвала настроек и
   текста приглашения убраны ссылки и формулировки про открытый исходный код и хостинг
   кода. Экран «О LIBO» теперь показывает версию, описание устройства и список из
   десяти возможностей (галочки прочтения, папки, пересылка, секретный таймер, опросы,
   код-замок, фоны, мультивыбор, глобальный поиск, без звука для чата).
2. **«Безопасность соединения» из настроек.** Ссылка в подвале настроек открывает
   сводку безопасности активного личного чата; без открытого чата она неактивна.
3. **Версия и бейдж.** `versionName 2.8.1`, `versionCode 20801`; бейдж в списке чатов —
   «v2.8.1» вместо «BETA 2.8».

Функции 2.5.0–2.8.0 сохранены полностью: голосовые, файлы и видео до 1,5 МБ, правки,
удаление для обоих, закреп, реакции, близкие контакты, статус «был(а) в сети», импорт
копии, сводка безопасности, QR личного кода, ответы, «Избранное», поиск в переписке,
MT-слой защиты (ECDH P-256 + AES-256-GCM, отпечаток пары), папки, пересылка, секретный
таймер, галочки прочтения, опросы, код-замок PIN, фоны, мультивыбор, глобальный поиск,
без звука для чата.

## Установка и обновление

1. Скачайте `LIBO-2.8.1.apk` из каталога `downloads/` тега `v2.8.1` и проверьте SHA-256.
2. Разрешите установку из браузера или файлового менеджера (Android 8–13), либо откройте

2.8.1, после чего импорт копии (архив только для чтения).

Модульные тесты (`npm test`) и браузерные сценарии (`npm run test:e2e`) прогоняются CI.
Сборка — `scripts/build-apk-local.sh` (без Gradle, закреплённый внешний toolchain) или
`./gradlew assembleDebug/assembleRelease` в среде с SDK Android. Манифест: код 20801,
minSdk 26, targetSdk 35, единственное разрешение `INTERNET`, `debuggable=false`.

## English summary

LIBO 2.8.1 is a patch release on the same signing key. It removes all open-source /
source-code-hosting mentions from the in-app UI (the «About» screen now lists version,
setup overview and ten features), wires the settings «Connection security» link to the
active chat's security summary, and bumps versionName to 2.8.1 (versionCode 20801).
All 2.5.0–2.8.0 functionality (MT-style protection layer, folders, forwarding, secret
timer, read receipts, polls, PIN lock, wallpapers, multi-select, global search, mute)
is preserved. Updates from 2.8.0 install in place without data loss.
