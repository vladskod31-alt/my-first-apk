# LIBO 2.3.0 — source review

## Зміни

- Кнопки-капсули, оновлені чати й елементи керування.
- П’ять палітр, колір кнопок, загальний фон, фон окремого чату, фотографії на фон із затемненням, колір вихідних повідомлень і розмір тексту.
- Реалізовано LIBO Cloud: підписані AES-256-GCM конверти, серверну чергу, зашифровану історію для обох сторін, відновлення профілю й історії з приватного файлу ключа.
- Окремий статус зберігання на сервері; доставка та прочитання залишаються відмінними подіями.
- Android: дозвіл на сповіщення, opt-in foreground service, два канали повідомлень, токен обмежених прав у Android Keystore, перезапуск служби після boot/package replacement.
- Фонові сповіщення не розкривають текст і не отримують ключі розшифрування повідомлень.
- Збережені прямий P2P-режим, парольна історія, нік/контакти/близькі, RU/UK/EN, SVG-емодзі, фото, відповіді, пошук та чернетки.
- Неперевірені хмарні записи не підтверджуються доставленими. Вони залишаються на сервері для повторної перевірки і не повинні блокувати інші розмови.

## Що потребує налаштування

Користувач обрав підготовку APK та сервера **без готового хостингу**. Постійний HTTPS-сервер ще не розгорнуто. Без нього лишається прямий режим з вимогою відкритих клієнтів. Для фонового режиму треба підключити сервер на обох пристроях, зберегти ключ відновлення, надати Android дозвіл і ввімкнути службу.

Це не Firebase/FCM. Постійне повідомлення про службу є частиною роботи foreground service. Android/виробник можуть обмежувати її роботу; без інтернету повідомлення чекають на сервері. Після force-stop застосунок потрібно відкрити вручну.

## Іконка — ще не завершено

JPG повністю підходить, PNG від користувача не потрібен. Оригінальні вкладення не доступні як файли в робочій папці, тому поточний APK **поки з попередньою іконкою**. Для точного встановлення потрібен доступний оригінальний JPG, наприклад усередині ZIP. Приблизну заміну без дозволу не зроблено. Додано локальний конвертер `scripts/apply-icon.mjs`.

## Сумісність та межі перевірки

Пакет `app.libo.messenger.preview23`, версія 2.3.0 / 20300, Android 8.0+. Це окрема тестова інсталяція, не оновлення старої 2.1: її ключ підпису тут недоступний. Не видаляйте стару програму з листуванням.

Виконано модульні й браузерні перевірки; фізичний Android, battery/Doze, boot та реальна система сповіщень ще потребують тестів. Протокол не проходив незалежного аудиту.
