## Додано

1. Локальний Wi-Fi/hotspot-канал за приватною IPv4-адресою (TCP 42888). Існуюче шифрування повідомлень, без сигнального сервера. Обидва телефони мають увімкнути локальний канал.
2. Експериментальний Wi-Fi Direct: пошук, системне спарювання, підключення до власника групи. Android 13+ — Nearby Wi-Fi Devices; до Android 13 — дозвіл і системна геолокація.
3. Голосові WebRTC-виклики: прийняти/відхилити, зайнято, mute, тайм-аут, завершити; дозвіл RECORD_AUDIO запитується лише під час вихідного або прийнятого виклику. SDP передається лише шифрованим автентифікованим каналом, аудіо — DTLS-SRTP.
4. NFC: читання й перезапис NDEF-мітки публічним запрошенням, перевірка формату та підтвердження контакту. Не Android Beam і не передача голосу через NFC.
5. Нове AI-зображення іконки у п’яти Android-плотностях, adaptive/round/monochrome, splash і вебверсії. Ресурси перевірено **в зібраному APK**, не лише у вихідному коді.
6. Пружне натискання кнопок, поява діалогів, анімований екран виклику з підтримкою reduced motion.

## Виправлено

- Manifest посилався на неіснуючий `ConnectionService` замість `KeepAliveService`.
- Нові локальні канали переживають перепідключення сигнального сервера і не надсилають повідомлення без E2EE.
- Відмова/скасування дозволу мікрофона не лишає активних медіатреків.
- Release CI не публікує непідписаний APK за відсутності секретів.
- Оновлені Vite і вразливі транзитивні dev-залежності; `npm audit` — 0 відомих вразливостей на момент перевірки.

## Результати перевірок

- **40/40 unit**, **13/13 браузерних сценаріїв**.
- Реальний WebRTC між двома ізольованими браузерними клієнтами, синтетичне джерело аудіо: отримані RTP-байти, mute, завершення, відхилення.
- Android Java → DEX → APK з підписом **v2/v3**, zipalign та AAPT2-перевіркою.
- **15/15 PNG** launcher-ресурсів: збіг розмірів і видимих пікселів із новою іконкою. `ICON-FROM-APK.png` витягнуто саме з APK; `ICON-VERIFICATION.json` містить результати.
- **Немає перевірки встановлення/запуску на фізичному телефоні або емуляторі.** Wi-Fi Direct/NFC та Android-мікрофон потребують перевірки на двох реальних пристроях. Не позначаємо їх як production-ready.

## Обмеження та оновлення

- Виклики працюють **тільки при відкритому LIBO**, без push-виклику, lock-screen UI та фонового мікрофона. Згортання/блокування завершує виклик.
- Для Інтернет-виклику/переписки потрібен signaling; для строгого NAT — налаштований TURN. Для голосу через Direct маршрутизація WebRTC залежить від Android/OEM. Bluetooth не переносить аудіо.
- Локальні адреси та публічний peer ID не є доказом особи: звіряйте номер безпеки. NFC-мітку можна підмінити; використовуйте довірену мітку.
- **Новий тестовий ключ підпису**, SHA-256 сертифіката: `2407e225945bae942bb0408078943f3adcbeb775a94e6418be70df3d659ff96a`.
- Ключ 2.8.7 недоступний, тому встановлення поверх старого APK з іншим сертифікатом Android відхилить. До видалення старого застосунку експортуйте текст і збережіть фото окремо. Експорт не переносить ключі, фото й налаштування; імпорт — архів лише для читання. Після видалення Android Keystore і стара ідентичність втрачаються.

Попередній тег `v2.8.7` не змінювався. [Інструкція](https://github.com/vladskod31-alt/my-first-apk/blob/arena/01a1013d-my-first-apk/docs/NEARBY.md).
