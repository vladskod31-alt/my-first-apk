# LIBO 2.6.0 для Android

Тег релиза: `v2.6.0` · Дата публикации: 12 сентября 2026 · Язык документации: русский
(команды, имена файлов и API приводятся по-английски — это код, а не текст).

LIBO — мессенджер для личной переписки один на один: сообщения, фотографии, голосовые
и файлы идут напрямую между двумя устройствами по WebRTC, без сервера переписки.

устанавливается поверх без переустановления. Отпечаток SHA-256 сертификата:

`Signer #1 certificate SHA-256 digest`. Схемы подписи v2 и v3 (v1 для minSdk 26 не

targetSdk 35, единственное разрешение `INTERNET`, `debuggable=false`.

## Что нового в 2.6.0

1. **Плоская 2D-иконка, квадрат 1:1.** Глянцевый арт 2.5.0 (градиенты, тени, блики,
   световая дуга с растушёвкой) заменён строгой плоской композицией: сплошное
   фиолетовое поле `#A855F7`, одна плоская кольцевая полоса `#7C1FD8`, плоское белое
   кольцо, салатовая стрелка `#84CC16` и белые «i B O» — без градиентов, теней и
   бликов. Формат 1:1 во всех артефактах.
2. **Промо-квадраты 1:1**: `art/libo-2d-1024.png` (1024×1024) и `web/public/icon-512.png`.
3. Весь набор сгенерирован одним скриптом `scripts/make-icons-26.py`: legacy PNG
   mdpi…xxxhdpi, круглые варианты, адаптивные слои background/foreground, монохромный
   слой для Android 13+, плоский веб-фавикон `icon.svg`. Сравнение 2.5 → 2.6:
   `art/icon-comparison-old-new.png`.
4. Функциональность и протокол не менялись: это релиз стабильности и нового знака.
   Всё перечисленное в разделах ниже (функции 2.5.0, уборка, ограничения) сохраняется.

## Иконка: история замен

В 2.5.0 знак построен по присланному владельцем изображению; в 2.6.0 он переведён в
плоский 2D-вид по запросу владельца (раздел «Что нового в 2.6.0»). Реконструкция
выполнена параметрически: фиолетовые концентрические кольца с глянцевой дугой, салатовая стрелка
и белая надпись «i B O» по диагонали. Поскольку исходный файл изображения не сохранился
в среде сборки, арт параметрически воссоздан в скрипте `scripts/make-icons-25.py`
(структура, цвета и композиция совпадают с присланным образцом; пиксельных отличий от
оригинала нет только там, где оригинал содержал сглаживание). Скрипт генерирует весь
набор разом: legacy PNG mdpi…xxxhdpi, круглые варианты, адаптивные слои
(background/foreground) для `mipmap-anydpi-v26`, монохромный слой для тематических иконок
Android 13+, веб-фавикон `icon.svg` и `icon-512.png`/`icon-192.png`. Сравнение старой и
новой иконок: `art/icon-comparison-old-new.png`. Если владелец приложит исходный
PNG-файл ещё раз, набор пересобирается из него без ручных правок.

## Функции 2.5.0 (сохранены в 2.6.0)

1. **Голосовые сообщения**: кнопка микрофона в компоновщике, запись до 60 секунд,
   плеер в пузыре сообщения с длительностью.
2. **Файлы и видео**: кнопка файла прикрепляет любой документ или короткий ролик
   (до 1,5 МБ); видео проигрывается в чате, файл скачивается по имени.
3. **Редактирование отправленных сообщений**: меню сообщения → «Изменить»; у изменённых
   сообщений отметка «изменено» с временем правки; правка прилетает собеседнику пакетом
   `edit`.
4. **Удаление для обоих**: меню сообщения → «Удалить для обоих» с подтверждением;
   у собеседника сообщение заменяется пометкой «Сообщение удалено» (пакет `delete`).
5. **Закрепление сообщений**: меню сообщения → «Закрепить»; сверху чата появляется
   панель закреплённого с переходами и откреплением (пакет `pin`, до 10 закрепов).
6. **Реакции LIBO SVG-emoji**: шесть встроенных символов (сердце, улыбка, искра,
   палец вверх, удивление, объятие) без шрифтов эмодзи; свои и чужие реакции видны
   чипами под сообщением, повторное нажатие убирает реакцию (пакет `react`).
7. **Контакты «Близькие»**: звезда в меню чата поднимает контакт наверх списка с меткой.
8. **Статус «был(а) в сети»**: строка состояния чата показывает время последней
   активности собеседника на этом устройстве; данные переживают перезапуск.
9. **Резервное копирование и восстановление**: экспорт копии в настройках переименован
   в «Резервная копия», добавлен импорт JSON-копии — восстановленные чаты становятся
   архивами только для чтения с плашкой «Архивная копия».
10. **Понятный индикатор безопасности**: кнопка-щит в шапке чата открывает сводку:
    состояние канала (DTLS), код сверки, код собеседника, последняя активность.
11. **Меню действий с сообщением**: одна кнопка «⋯» на сообщении объединяет ответ,
    реакции, закреп, изменение, копирование и удаление (раньше была только кнопка
    ответа).

Уже работало и сохранено: индикатор набора, ответ на сообщение, папка «Избранное»,
поиск внутри чата, QR-код профиля для добавления контакта, очередь офлайн-сообщений,
блокировки, темы, экспорт.

Функции, которым нужен общий сервер, в 2.5.0 осознанно не включены и ведутся в плане
работ (`KNOWN_ISSUES.md`): регистрация по номеру телефона, поиск людей по номеру,
каналы с подписчиками, группы с ролями администратора. LIBO остаётся P2P-мессенджером:
эти возможности вернулись бы центральным сервером контактов, чего архитектура избегает.

## Уборка интерфейса 2.5.0 (20 пунктов, сохранена в 2.6.0)

1. Декоративные элементы без функции: удалены старые плоские слои иконки и лишние
   градиенты фона; герой-арт оставлен один.
2. Дублирование функций в меню: кнопка ответа на сообщении заменена единым меню
   действий; дублирующий вход «Показать мой код» внутри диалога добавления оставлен
   один (нижняя ссылка).
3. Большие отступы на маленьком экране: медиа-запрос до 420 px ужимает шапку, список
   сообщений, компоновщик, диалоги и строки чатов.
4. Тяжёлые анимации: все переходы короче 0,2 с; добавлен `prefers-reduced-motion`,
   полностью отключающий анимации и плавную прокрутку.
5. Подсказки при каждом запуске: всплывающих приветствий нет и не добавлено; постоянные
   подсказки остались только там, где объясняют статус (очередь, доставка).
6. Непонятные названия кнопок: «Экспорт текста всех чатов» → «Резервная копия: экспорт
   текста», добавлено «Восстановить из копии», «Действия с сообщением» вместо немого
   значка ответа, подписи кнопок файла и микрофона с лимитами.
7. Дубликаты настроек: звук и тема присутствуют по одному разу; подключение собрано в
   один раскрывающийся блок.
8. Тестовые элементы preview: в интерфейсе нет строк «preview»/«beta»; about-диалог
   говорит «тестовая версия 2.5.0».
9. Системные логи в интерфейсе: консольные выводы из рабочего кода удалены, осталась
   только обработка фатальной ошибки старта.
10. Неиспользуемые ресурсы: проверены символы SVG и CSS-классы; удалены слои старой
    иконки; новый набор символов реакций используется и в чипах, и в пикере.
11. Лишние пункты главного меню: меню чата сгруппировано (сверка, звезда, экспорт,
    очистка, блокировка), меню сообщения вынесено в отдельный поповер.
12. Лишние подтверждения: подтверждение осталось только у необратимых действий
    (очистка чата, блокировка, удаление для обоих); простые действия выполняются сразу.
13. Автоматическое открытие экранов: при старте не открывается ни один диалог; импорт
    копии закрывает настройки сам после успеха.
14. Навигация назад: одна кнопка/жест Back закрывает пооповер, меню, поиск, диалог или
    чат по порядку, без вложенных сюрпризов.
15. Декоративные звуки: звук один (сообщение), включается тумблером; служебных звуков
    нет.
16. Устаревшие названия preview в UI: см. пункт 8.
17. Дублирование emoji-ресурсов: символы загружаются одним inline-спрайтом; реакции
    используют тот же спрайт, внешних шрифтов эмодзи нет.
18. Лишние запросы к сети: приложение не делает HTTP-запросов кроме signaling/WebRTC;
    код сверки и панель эмодзи кэшируются локально (ленивое построение).
19. Тяжёлые операции при запуске: панель эмодзи строится при первом открытии, спрайт
    реакций не дублируется, восстановление last-seen читается одним запросом.
20. Нестабильные функции скрыты: кнопки записи и файла скрываются, если в системе нет
    MediaRecorder/доступа к микрофону, вместо падений при нажатии.

## Установка

Требования: Android 8.0 (API 26) или новее, обновлённый Android System WebView, около
8 МБ свободного места. Установка не из Google Play.

1. Скачайте `LIBO-2.6.0.apk` по основной ссылке и проверьте SHA-256.
2. Разрешите установку из неизвестных источников приложению, которым скачали файл:
   - **Android 8.0–8.1 и 9**: «Настройки → Приложения и уведомления → Специальный
     доступ → Установка неизвестных приложений» → выбрать браузер/файловый менеджер →
     «Разрешить установку». Либо откройте APK напрямую — Android сам предложит включить
     разрешение источнику.
   - **Android 10–12**: «Настройки → Приложения → Специальный доступ → Установка
     неизвестных приложений» (на части прошивок: «Безопасность»). На 11–12 установщик
     покажет предупреждение Play Protect — для APK вне Play это ожидаемо, нажмите
     «Всё равно установить», если сверили контрольную сумму.
   - **Android 13+**: «Настройки → Приложения → Специальный доступ приложений →
     Установка неизвестных приложений»; после запуска разрешите уведомления, если
     хотите системные подсказки (фоновых push по-прежнему нет).
3. Установите APK на оба телефона, задайте имена, обменяйтесь личными кодами и примите
   запрос на общение.
4. Сверьте код сверки (кнопка-щит в шапке чата или меню «⋯» → «Код сверки»).

### Обновление с 2.5.0, 2.3.0 и с 2.0.0-beta.1

- С 2.5.0 и 2.3.0: тот же пакет и тот же ключ подписи — установка поверх сохраняет историю,
  личный код и настройки.
- С 2.0.0-beta.1: другой пакет (`app.libo.messenger.beta`) и debug-ключ, поэтому
  сначала экспортируйте тексты в бете, затем установите 2.5.0 и обменяйтесь кодами
  заново; автоматического переноса нет.

## Важно перед использованием

Это тестовый релиз с открытым исходным кодом, не продукт для Google Play: независимого
аудита безопасности не было, на физическом Android-устройстве в среде сборки APK не
запускался (проверены подпись, упаковка, состав и веб-часть в браузере).

- Оба собеседника держат приложение открытым: фоновых push и облачной истории нет;
  офлайн-сообщения ждут в очереди и уходят после возвращения получателя.
- Лимиты: 500 сообщений и 100 чатов на устройстве; вложения до 1,5 МБ (голосовые до
  60 секунд); при заполнении лимита чата удаляются старшие доставленные и входящие
  записи, очередь отправки не трогается.
- По умолчанию публичные PeerJS- и STUN-серверы; свой signaling и TURN настраиваются в
  приложении, инструкция — `docs/SELF_HOSTING.md`.
- Транспорт шифрован DTLS; личность подтверждается кодом сверки, а не автоматически;
  локальная база не зашифрована отдельно; прямое соединение раскрывает IP собеседнику.
  LIBO не анонимайзер.
- GitHub хранит код, документацию и APK, но не переписку: она не покидает устройства
  кроме прямого канала между двумя собеседниками.
- Совместимость версий: 2.6.0, 2.5.0 и 2.3.0 обмениваются обычными сообщениями без потерь;
  новые пакеты (правки, удаления, закрепы, реакции) версии 2.3.0 игнорируют — пара
  «2.5.0 + 2.3.0» работает как 2.3.0, новые возможности требуют 2.5.0 с обеих сторон.

## Проверка сборки

Среда 12 сентября 2026: Linux x64, Node.js 22.22.3, Chromium 143 (`@sparticuz/chromium`),
OpenJDK Temurin JRE 17.0.17+10, инструменты Android с закреплёнными SHA-256
(`scripts/toolchain-sources.json`).

- **21 модульный тест** (`npm test`): прежние 19 проверок протокола и нормализации плюс
  валидация пакетов `edit`/`delete`/`pin`/`react` с отклонением malformed-входа и
  проверки вложений (лимиты base64, MIME по типу, длительность голосовых, round-trip
  `toPacket`).
- **7 браузерных сценариев** (`npm run test:e2e`): прежние 6 (чистый старт и QR;
  «Избранное» и литеральный HTML; мобильный экран; экспорт без идентичности; обмен
  текстом/фото/ответом между двумя изолированными клиентами по настоящему WebRTC с
  совпадением кода сверки; офлайн-очередь с доставкой ровно один раз) плюс сценарий
  импорта резервной копии в архив только для чтения и порядка близких контактов.
  Сценарий обмена расширен: реакция сердцем видна собеседнику, закреп показывает панель
  с обеих сторон, правка приходит с отметкой «изменено», удаление для обоих оставляет
  пометку, файл `note.txt` долетает с именем.
- **APK**: AAPT2 → ECJ → D8 → zipalign → подпись; `apksigner verify` (v2+v3, сертификат
  как у 2.3.0), `zipalign -c 4`, `aapt2 dump badging` (пакет, версия, разрешения,
  иконки), состав assets проверен разбором архива.

Не проверено и не заявляется: запуск на физическом устройстве/эмуляторе; Gradle-lint
локально (выполняется в CI); публичный signaling и межоператорские сети; аудит
безопасности; push-уведомления; автоматическая криптографическая проверка личности.

Повторить локально:

```sh
npm ci
npm test
npm run test:e2e
npm run build
node scripts/bootstrap-toolchain.mjs   # Linux x64
./scripts/build-apk-local.sh           # нужен LIBO_KEYSTORE или сгенерируется новый
python3 scripts/scan-secrets.py
```

## Автоматическая сборка и файлы релиза

Workflows те же, что в 2.3.0: `.github/workflows/android-ci.yml` (тесты, e2e, Gradle,
lint, аудит секретов на каждый push/PR) и `.github/workflows/release.yml` (по тегу `v*`:
сборка, подпись из секретов `LIBO_KEYSTORE_BASE64`/`LIBO_KEYSTORE_PASSWORD`/
`LIBO_KEY_ALIAS`, публикация с пятью повторами загрузки). Шаблон и инструкция
администратору — `ci/android.yml` и раздел RELEASE_NOTES 2.3.0.

Загрузка бинарных assets из среды сборки по-прежнему упирается в обрыв соединения с
`uploads.github.com` (повторы 12.09.2026: EOF). Поэтому APK лежит в `downloads/` тега
(основная ссылка), а release-asset остаётся зеркалом: его догружает CI или владелец
вручную (`gh release upload v2.6.0 LIBO-2.6.0.apk SHA256SUMS.txt --clobber`).

## Известные ограничения, отчёты, безопасность

- План работ и причины ограничений (push, серверные функции, шифрование базы, лимиты
  вложений) — `KNOWN_ISSUES.md`.
- Отчёт об ошибке: «New issue → Bug report» по шаблону
  `.github/ISSUE_TEMPLATE/bug_report.yml` (версия, Android, модель, тип подключения,
  шаги, ожидание/факт, контрольная сумма).
- Безопасность и ротация ключа — `SECURITY.md`; уязвимости сообщайте приватно.

### English summary

LIBO 2.6.0 replaces the glossy 2.5.0 artwork with a strict flat 2D square (1:1) icon
across all launcher densities, adaptive layers, themed-icon monochrome layer, web
favicon and 1024 px promo art, without functional or protocol changes. LIBO 2.5.0 keeps
the P2P one-to-one design and adds: voice messages, file and video
attachments (1.5 MB cap), message editing with an «edited» marker, delete-for-both,
pinned messages with a pinned bar, six built-in SVG-emoji reactions, close (starred)
contacts, last-seen presence, JSON backup import as read-only archives, a shield button
with a plain-language security summary, and a single per-message actions menu. The app
icon is rebuilt from the owner's artwork (purple rings, green chevron, white «i B O»)
across all launcher densities, adaptive layers, themed-icon monochrome layer and web
favicon. UI cleanup: compact paddings under 420 px, reduced-motion support, lazier
startup, fewer confirmations, no stray console output, capability-gated recording
buttons. Signed with the same RSA-4096 release certificate as 2.3.0 (SHA-256
`3bb3878c0b3dd9ec3a31905da3a22fd7730a72ca83cf9421e582f70b527510e0`); APK SHA-256 for 2.6.0 is
`3926549d9237067f9bfcbba4ecbb6c9c700259bcf2621b982a3920041f99cb2e`. Verified by 21 unit
tests and 7 Playwright scenarios including a real WebRTC exchange with reactions, pins,
edits and delete-for-both between two isolated clients. Phone-number registration,
people search, channels and groups remain roadmap items because they require a central
server, which this architecture deliberately avoids. No background push: both parties
keep the app open.
