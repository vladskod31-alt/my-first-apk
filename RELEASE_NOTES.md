## Нові функції

- **Orbit Premium**: 300 віртуальних монет → 7 днів палітр Ocean/Sunset/Violet і відсутності рекламного блоку. Без автопродовження. Чати, виклики та шифрування залишаються безкоштовними.
- **Монети / зірки LIBO**: бонус +100/+5 щодня UTC; обмін 50 монет на 5 зірок; локальна косметична колекція по 10 зірок; останні 100 операцій. Збереження атомарне, подвійний бонус у вкладках відхиляється.
- **Рекламна студія**: власні кампанії, текст/бренд/картинка/HTTPS-посилання, розклад, cap, cooldown, вага, редагування/пауза/видалення, JSON імпорт/експорт.
- **Advertising API v1**: feed, optional events, Bearer-auth CRUD та статистика. Self-hosted Node-сервер у `server/`, з обмеженням запитів/даних і атомарним записом кампаній. Сервер ще не розгорнутий публічно.
- Реклама та статистика — окремі opt-in налаштування, за замовчуванням вимкнені. Приватні чати не читаються для реклами; зовнішні зображення/пікселі, SVG і script URL відхиляються. Картка позначена «Реклама» і не з’являється в розмові.
- Android file picker виправлено для JSON та файлів; експорт кампаній використовує системний діалог збереження.

## Важливі межі

**Це не повна копія Telegram.** Групи, канали, хмарна історія/синхронізація, боти, stories, відеовиклики й реальні платежі не реалізовані у цьому патчі. Докладно — `docs/TELEGRAM-SCOPE.md`.

Premium/монети/зірки — **локальна демо-економіка без грошової вартості**, не Telegram Stars. Немає купівлі за гроші, виведення, переказів, серверної перевірки покупки чи доходів за рекламу. Годинник/дані власник може змінити. Локальна кампанія видима тільки на цьому пристрої; для інших потрібен налаштований власний API. Статистика недовірена, не придатна для білінгу.

Збережено функції 2.8.8. Direct/NFC потребують реальних пристроїв; виклики лише при відкритому застосунку. Незалежного аудиту криптографії/безпеки немає.
