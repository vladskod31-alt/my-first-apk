# Иконка LIBO 2.3

JPG подходит: PNG от пользователя не требуется. Оригинальные вложения из чата отображаются визуально, но файлы `IMG_20260908_130021_534.jpg` и `IMG_20260908_131412_813.jpg` отсутствуют по переданным путям и не найдены в рабочей среде.

Изображение **не подменено выдуманной копией**. Текущий тестовый APK пока сохраняет прежнюю иконку. Чтобы установить именно присланный оригинал, нужен доступный JPG — например, внутри ZIP-архива.

После получения файла:

```bash
node scripts/apply-icon.mjs /path/to/original.jpg
```

Скрипт локально сохраняет оригинал, преобразует его в PNG для Android/веба, создаёт размеры launcher-иконок и записывает `branding/icon-installed.json`. Затем необходимо заново собрать и проверить APK. Секреты и картинки никуда не загружаются.
