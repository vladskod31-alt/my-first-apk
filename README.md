# Swamp Attack

Аркадна офлайн-гра для Android: захищайте болотну хатину від хвиль кумедних монстрів.

![Іконка гри](art/swamp-attack-icon-1x1.png)

## Можливості

- повноцінний ігровий цикл із хвилями та зростанням складності;
- три види зброї: дробовик, гвинтівка та бомби;
- різні вороги, здоров’я хатини, монети й майстерня покращень;
- збереження рекорду, монет, звуку та придбаних покращень;
- адаптивне сенсорне керування й примусова альбомна орієнтація в APK;
- гра повністю працює офлайн.

## Графіка

- квадратна іконка 1:1: [`art/swamp-attack-icon-1x1.png`](art/swamp-attack-icon-1x1.png);
- заставка 16:9: [`art/swamp-attack-splash-16x9.jpg`](art/swamp-attack-splash-16x9.jpg).

Обидва зображення створені спеціально для цього проєкту. Android-іконки для всіх щільностей екрана згенеровані з квадратного оригіналу.

## Запуск і збірка

```sh
npm ci
npm run dev       # локальний перегляд
npm run build     # створити web-бандл у dist/
./gradlew assembleDebug
```

Готовий тестовий APK: [`downloads/Swamp-Attack-1.0.0.apk`](downloads/Swamp-Attack-1.0.0.apk). APK підтримує Android 8.0 і новіші версії.
