# my-first-apk

## LIBO Утиліта (окремий Android-застосунок)

Окрема утиліта для роботи разом із LIBO. Нічого не змінює в самому LIBO
(`LIBO_v-1.4.6_SUPER_MEGA_STABLE-6.html`) — це окремий застосунок.

Можливості:
- **Контакти**: зберігання імені, номера телефону та нотатки; пошук; дзвінок,
  копіювання номера, редагування й видалення; експорт у CSV (з підтримкою українських літер).
- **Фото / відео**: імпорт декількох файлів з телефону, сітка з прев'ю,
  перегляд на весь екран (відео з керуванням), видалення (довге натискання).
- Усі дані зберігаються тільки на пристрої (SQLite + приватна папка застосунку).
  Жодних дозволів на інтернет чи доступ до контактів не потрібно.

### Де код
`libo-utility/` — Android-проєкт (Java, без зовнішніх залежностей).

### Як отримати APK
APK збирається автоматично через GitHub Actions (workflow `Build LIBO Utility APK`):
1. Відкрийте вкладку **Actions** у репозиторії.
2. Оберіть останній успішний запуск і завантажте артефакт **libo-utility-debug-apk**.
3. Перенесіть `app-debug.apk` на телефон і встановіть
   (дозвольте встановлення з невідомих джерел).

Або зберіть локально: `cd libo-utility && gradle assembleDebug`
(потрібні JDK 17 та Android SDK з платформою 34).
