# my-first-apk

Цей репозиторій також містить незалежний Ruby-проєкт **DBA Materials Scanner** у [`dba-materials-scanner/`](dba-materials-scanner/README.md). Він відстежує нові матеріали в RSS/Atom/JSON Feed або на налаштованій публічній HTML-сторінці та підтримує консольні, webhook і Telegram-сповіщення.

Для запуску потрібні Ruby 3.1+ та Bundler. URL конкретного DBA-джерела потрібно задати локально через `DBA_SOURCE_URL`; документація і приклад конфігурації лежать у підкаталозі проєкту.

Існуючий HTML-файл `LIBO_v-1.4.6_SUPER_MEGA_STABLE-6.html` залишено без змін.
