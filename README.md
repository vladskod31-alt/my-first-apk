## Нове у 2.8.9.1

- **Orbit Premium**: 300 віртуальних монет за 7 днів власних палітр і відсутності рекламної картки. Без автопродовження; шифрування, чати й виклики не стають платними.
- **Монети та зірки LIBO**: щоденний бонус 100/5, обмін 50 монет → 5 зірок, косметична колекція й історія. Атомарні IndexedDB-транзакції захищають від подвійного бонусу у вкладках. **Без грошової вартості, платежів, виведення або переказів.**
- **Рекламна студія**: створення/редагування, зображення, бренд, HTTPS-посилання, розклад, пауза, вага ротації, локальний cap і cooldown, JSON імпорт/експорт.
- **Self-hosted Advertising API**: public feed/events, захищений Bearer-токеном CRUD і агрегована статистика. **Код сервера є, публічний сервіс автоматично не розгорнуто.**
- Реклама й статистика **вимкнені за замовчуванням**. Немає таргетингу за приватними чатами. Картка «Реклама» лише на welcome, не в листуванні; зовнішні tracking images/SVG заборонені.
- Android file picker тепер підтримує JSON та довільні вкладення, а не тільки фотографії. Експорт кампаній використовує системне збереження файлу.

[Економіка та студія](docs/ORBIT.md) · [API та запуск](docs/ADS-API.md) · [Що є і чого немає порівняно з Telegram](docs/TELEGRAM-SCOPE.md)

> **Не «всі функції Telegram».** Групи, канали, хмарна синхронізація, Bot API, stories, відео та реальні платежі не додані. Збережено існуючі особисті чати, медіа, реакції, стікери, опитування, E2EE, Wi-Fi/Direct/NFC та foreground WebRTC-виклики LIBO. Direct/NFC залишаються експериментальними.

## Перевірка

47 unit/API тестів та 17 браузерних сценаріїв пройдено локально й у CI. Gradle assembleDebug та блокувальний Android lint — успішні. Включено дві вкладки гаманця, закінчення Premium, згоду на рекламні запити, cap, безпечний текст і відхилення зовнішніх зображень; регресійні тести чатів та справжнього WebRTC-аудіоканалу із синтетичним звуком.

APK зібраний, підпис v2/v3 і zipalign перевірені. Нову іконку 2.8.8 збережено; всі 15 PNG і adaptive/splash-посилання повторно перевірено в APK 2.8.9.1. **Android 35 emulator: встановлення підписаного APK, запуск, WebView та відкриття Orbit пройдено** ([звіт](https://github.com/vladskod31-alt/my-first-apk/actions/runs/37303373445)). Фізичні Wi-Fi Direct/NFC, чутні дзвінки між телефонами й повний Android UI не перевірені. [Тести](TESTING.md), [обмеження](KNOWN_ISSUES.md).

## Важливо перед встановленням

**Новий тимчасовий підпис**: попередній приватний ключ недоступний у цій сесії. Android не встановить його поверх APK з іншим сертифікатом. Не видаляйте старий LIBO без збереження важливого: текстовий експорт не переносить фото, ключі, налаштування чи Orbit-гаманець. Імпорт — архів лише для читання. [Інструкція](downloads/README.md).

Orbit — локальна демо-економіка, яку можна змінити годинником/редактором даних. Не використовуйте баланс або рекламні події як доказ оплати. Реальних рекламних доходів не обіцяємо.

## Розробка

```sh
npm ci
npm test
npm run test:e2e
npm run dev        # 0.0.0.0:5173, браузерний preview
npm run build
./gradlew assembleDebug  # Android SDK, JDK 17
# Альтернативна toolchain:
node scripts/bootstrap-toolchain.mjs
# export JAVA_HOME=... LIBO_TOOLCHAIN=... (bootstrap друкує шляхи)
bash scripts/build-apk-local.sh
python3 scripts/verify-apk-icons.py artifacts/LIBO-2.8.9.1.apk
# Власний рекламний сервер; спершу прочитайте docs/ADS-API.md:
npm run ads:serve
```

Android/UI-версія — `2.8.9.1`; npm-версія — SemVer `2.8.9-1`. Скрипт APK читає `versionName` з Gradle. `server/` не входить у APK, лише клієнт API з `web/`.

Релізи, APK, patch та документація публікуються на GitHub. Google Play, сторонні магазини й реальні рекламні мережі не налаштовані. Короткий GitHub About залежить від прав інтеграції; основний опис — цей README.
