# Межі публікації

12 вересня 2026 користувач попросив відкрити pull request. Після явного попередження, що репозиторій має видимість Public і PR відкриє вихідний код, користувач підтвердив публікацію коду LIBO 2.3.

Цей дозвіл поширюється на код LIBO 2.3 для публічного PR з гілки `arena/01a0708b-my-first-apk`. Попередню заборону публікації коду 2.3 змінено саме в цих межах.

**Не включати до PR:** APK, ZIP-архіви, локальні HTML-сторінки з вбудованим APK, ключі підпису, паролі, `.env`, бази або особисту переписку. Вони залишаються локальними й ігноруються Git. Раніше опубліковані 2.0/2.1 артефакти в історії не переписуються; з поточного дерева відстежувані APK прибираються.

Публікація PR не розгортає хостинг, не підтверджує номер через SMS і не означає аудит чи перевірку на фізичному Android. Готова серверна частина потребує постійного HTTPS-хостингу. Оригінальний файл іконки досі недоступний; приблизну заміну без дозволу не зроблено.
