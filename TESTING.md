# Тестирование LIBO 2.8.7

## Автоматические тесты

```bash
npm ci
npm test                # 34 юнит-теста: node --test tests/*.test.mjs
npx playwright install chromium   # один раз
npx playwright test     # 11 e2e-сценариев (встроенный dev-сервер + peerjs-сигналинг)
```

### Юнит-тесты (`tests/core.test.mjs`, `tests/e2ee.test.mjs`)
- Ядро: коды/отпечатки, нормализация, очереди, версия и константы фич.
- Хранилище: vault-обёртка (AES-256-GCM), миграция мета-записей.
- **E2EE**: рукопожатие X25519/Ed25519, Double Ratchet (порядок, пропуск, смена цепи),
  ChaCha20-Poly1305, закрепление идентичности, смена ключа видна пиру,
  защита от даунгрейда (открытый текст после E2EE-оффера игнорируется).

### E2E (Playwright, `tests/app.spec.mjs`, `tests/smoke287.spec.mjs`, `tests/motion287.spec.mjs`)
1. Приветственный экран, честные контакты, валидный QR, версия, без open-source-заявлений в UI.
2. «Избранное», экранирование HTML, черновики, поиск, тема, перезагрузка.
3. Мобильная навигация, валидация ввода, профиль, без горизонтального переполнения.
4. Экспорт текста: заметки есть, приватные идентификаторы контактов отсутствуют.
5. Два независимых клиента: текст, ACK доставки, ответ, реальное фото.
6. Офлайн-очередь переживает перезагрузку отправителя и доставляется ровно один раз.
7. Импорт копии → архив только для чтения; близкие контакты сверху.
8. Опросы, пересылка, отметки прочтения, MT-слой, секретный таймер между двумя клиентами.
9. Функции 2.8.7: форматирование, спойлеры, тихая отправка, никнейм, закреп/архив,
   расписание, стикеры, сессии.
10. Смоук 2.8.7: настройки уведомлений + Bluetooth-диалог + отсутствие ошибок консоли.
11. Motion 2.8.7: ripple по pointerdown, радиусы диалогов 28px, `prefers-reduced-motion`
    отключает ripple.

## Ручной чек-лист на Android-устройстве

Установка: см. `downloads/README.md` (предыдущую сборку удалить — подписи различаются;
сначала экспортировать копию).

1. **Иконка**: на домашнем экране видна новая иконка (фиолетовый градиент, белый пузырь,
   зелёные шевроны); в Android 13+ тематические иконки показывают monochrome-слой.
2. **Сплэш**: холодный запуск — сразу фиолетовое окно с логотипом, затем анимированный
   SplashView, без чёрного кадра; то же в тёмной теме и на Android 12+ (системный сплэш).
3. **Блокировка**: задайте PIN в настройках безопасности; при сворачивании приложение
   блокируется; биометрия (если есть) разблокирует; скриншоты не делаются (FLAG_SECURE).
4. **Уведомления**: Настройки → «Проверить уведомления» → системное уведомление приходит;
   сверните приложение, отправьте сообщение со второго устройства — уведомление появляется,
   тап открывает нужный чат; с выключенным «Показывать текст» приходит только «Новое сообщение».
5. **Bluetooth P2P**: на двух устройствах включите Bluetooth, «Принимать подключения»;
   на одном — «Сделать видимым», на другом — «Найти устройства»; подключитесь, обменяйтесь
   сообщениями с выключенным Wi-Fi/мобильными данными; в шапке чата — «Рядом · Bluetooth ·
   сквозное шифрование».
6. **Фоновый режим**: включите переключатель — появляется тихое уведомление «LIBO на связи»;
   сообщения доходят при свёрнутом приложении (на агрессивно экономящих батарею оболочках
   добавьте LIBO в исключения — см. `KNOWN_ISSUES.md`).
7. **Анимации**: ripple на нажатиях + вибро-отклик, отправка сообщения — «прыжок» кнопки;
   включите «Удаление анимации» в спецвозможностях системы — декоративные анимации исчезают.
8. **E2EE**: добавьте контакт личным кодом, сверьте номер безопасности при встрече;
   смена устройства собеседника показывает предупреждение о смене идентичности.

## Сборка APK локально

```bash
export JAVA_HOME=<путь из bootstrap-toolchain>/runtime/jre
export LIBO_TOOLCHAIN=<путь>/android
./scripts/build-apk-local.sh   # → artifacts/LIBO-2.8.7.apk (подпись v1+v2+v3)
```

Проверка подписи и версии:
`$LIBO_TOOLCHAIN/apksigner verify --print-certs artifacts/LIBO-2.8.7.apk`,
`$LIBO_TOOLCHAIN/aapt2 dump badging artifacts/LIBO-2.8.7.apk | head -2`.
