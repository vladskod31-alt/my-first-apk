### Что покрывают тесты

- Обязательный ник, нормализация Unicode и телефона, отсутствие приглашений и публичных ссылок.
- Строгие размеры/типы пакетов, raster-only изображения, безопасный текст без HTML-инъекции.
- Подпись hello, запрет передачи телефона/закрытого ключа в hello, ECDH/HKDF и разные ключи направлений, AES-256-GCM, подмена/повтор/старый сеанс, отсутствие plaintext downgrade.
- Шифрование всех приватных записей, непрозрачные ID чатов, неправильный пароль, привязка AAD, ротация, отключение, параллельная очередь записей и откат прерванной миграции.
- API SMS с **явно внедрённым тестовым провайдером**: нет сервиса по умолчанию, неверные коды, лимиты/срок действия, подпись профиля, одноразовое погашение challenge, token authorization, opt-in поиска и удаление аккаунта. Отдельный тест проверяет формирование реальных Twilio Verify запросов; он не отправляет SMS.
- Реальные два независимых P2P-клиента через локальный сигналинг: текст, ответы, фото, шифротекст в RTCDataChannel, сохранение до ACK, отдельный READ после принятия и видимости, отсутствие READ для сообщений за пределами экрана, поздний ACK без понижения статуса, повторы READ после перезапуска, отключение отметок.
- Смена ключа блокирует доставку. Офлайн-очередь переживает перезапуск и не дублируется при обоих порядках адресов; исправлена обработка старых offer из брокера.
- Контакты, локальные имена, «Близкие», черновики, поиск, темы, локализация и отсутствие переполнения на 360 px.
- Все **3395 вариантов / 1870 базовых записей** каталога Emoji Mart 15.0 имеют локальный SVG; архив содержит **3720 SVG**. Выбор новых Emoji 15.0 и скачивание архива проверены.
- Парольное хранилище очищает приватный DOM при уходе в фон; незавершённая разблокировка не открывает фон; выбранная фотография показывается только после пароля. Второе окно профиля не может участвовать в миграции.
- Экспорт требует предупреждения о plaintext. Dev-server не отдаёт базу аккаунтов, `.git/config` и серверные файлы через `/@fs`.

### Проверка ресурсов итогового APK

`scripts/test-packaged.mjs` извлекает файлы **из самого APK**, открывает их в Chromium по `https://appassets.androidplatform.net` с CSP из нативного загрузчика и блокирует внешний HTTP/WebSocket-трафик. Проверены: первый запуск, офлайн-заметки, SVG, украинский интерфейс/поиск, парольное хранилище, блокировка, перезагрузка и ширина 390 px. Нативный JavaScript bridge **подменён заглушкой**: это не тест Android, Intent, `FLAG_SECURE` или настоящего системного выбора файлов.

## Ещё не проверено

- Установка, ввод, фон, поворот, блокировка экрана, недавние приложения и системные диалоги на физическом Android или эмуляторе.
- Настоящие SMS, биллинг, политика провайдера и операторы связи.
- Публичный сигналинг, разные провайдеры/мобильные сети, собственный TURN и долговременная эксплуатация.
- Независимый аудит криптографии, нагрузка большой истории и реальные сбои диска Android.
